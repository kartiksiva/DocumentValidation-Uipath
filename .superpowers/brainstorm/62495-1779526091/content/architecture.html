System Architecture

Layered design — swap UI layer without touching Maestro pipeline. Click any layer to select it for discussion.

🖥️ UI Layer Swappable
UiPath Coded App (v1) React-based, hosted on UiPath Platform
Upload Screen PDF/Word, mode selector, version picker
Results Screen Scorecard + Diff + Summary + Confirm/Reject
Custom React App (future) Drop-in replacement via same API
↕ REST / SDK calls
⚡ API / Integration Layer UI-Agnostic
Node.js / Express API Typed endpoints, input validation
UiPath TS SDK @uipath/uipath-typescript v1.3.8
Bucket Handler Upload docs → UiPath Buckets, version tracking
Webhook / Polling Listen for Maestro process completion
↕ Maestro SDK
🎯 Maestro Orchestration Layer Core
ContractComparisonProcess Main Maestro process entry point
Mode Router Buyer/Seller diff vs Template compliance
Human Task Business user confirm / reject step
Version History Gate Optional: fetch prior versions from Buckets
↕ Agent calls
🤖 AI Agent Pipeline
Agent 1: Extractor DU → text + structure from PDF/Word
Agent 2: Comparator LLM — clause-by-clause diff + gap analysis
Agent 3: Reviewer Generates scorecard + diff + narrative
↕
🗄️ Storage
UiPath Buckets Contract files + version history
Process Results Comparison outputs, audit log
Assets LLM config, template docs, thresholds
Key principle: Maestro + Agent Pipeline know nothing about the UI. All UI changes stay above the API layer.
