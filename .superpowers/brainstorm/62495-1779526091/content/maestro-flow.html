Maestro Workflow — ContractComparisonProcess

End-to-end flow from document upload to confirmed review. Scroll down to see full pipeline.

1. Upload & Trigger Coded App → SDK

User selects mode (Buyer/Seller diff or Template compliance) + uploads 2 docs (PDF/DOCX). Optional: toggle "Include version history". SDK uploads files to UiPath Buckets, then calls MaestroProcesses.start() with params.

Mode A — Buyer vs Seller diff
Compare two contract versions clause-by-clause
Mode B — Template compliance
Contract vs standard template, flag deviations

2. Agent 1 — Extractor Document Understanding

Pulls both documents from Buckets. Uses DU to extract structured text — clause headings, sub-clauses, definitions, signature blocks. Handles PDF (native + scanned/OCR) and DOCX. Outputs structured JSON per document.

Optional: Version History
If toggled: fetch prior versions from Buckets by contract ID. Extractor runs on each prior version too.

3. Agent 2 — Comparator LLM

Takes structured JSON from Extractor. Runs clause-by-clause comparison. Identifies: added/removed/modified clauses, risk deltas (liability cap changes, IP ownership shifts, termination triggers), missing standard clauses. Outputs raw findings JSON.

4. Agent 3 — Reviewer LLM

Formats Comparator output into 3 structured outputs:
• Risk Scorecard — RAG per category (Payment, Liability, IP, Termination, Confidentiality)
• Side-by-side diff — clause pairs with change type tags
• Narrative summary — plain-English, business-user level, key risks + recommendations

5. Human Task Created Maestro → Tasks SDK

Maestro creates Human Task with full review payload. Task surfaces in Coded App via Tasks SDK — same UI the user uploaded from. Business user sees full scorecard + diff + summary.

✓ Confirm
Results finalized. Stored in Buckets with audit log. Case closed in Maestro.
✗ Reject
User adds rejection note. Case flagged for manual review / escalation. Maestro marks incomplete.

6. Storage & Audit Buckets

All inputs + outputs stored: source docs, extracted JSON, comparison findings, final review, user decision + timestamp. Enables version history lookup in future runs.
